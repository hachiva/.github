# Contributing to Hachiva

Thank you for your interest in contributing to Hachiva.

Contribution policies may vary between repositories. Before submitting an issue or pull request, please review the repository's README and documentation.

## Before Contributing

- Search existing issues and pull requests to avoid duplicates.
- Open an issue before proposing substantial changes.
- Keep pull requests focused on a single purpose.
- Include tests and documentation where applicable.
- Do not commit credentials, secrets, personal data, or proprietary information.
- Follow the repository's existing code style and conventions.

## Reporting Bugs

Use the repository's bug report form and provide clear reproduction steps, environment details, and relevant context.

## Suggesting Features

Describe the underlying problem before proposing a solution. Explain the expected benefit and any alternatives considered.

## Security Issues

Do not report security vulnerabilities through public issues, discussions, or pull requests.

Please follow our [Security Policy](SECURITY.md) and contact `security@hachiva.com`.

## Pull Requests

Before submitting a pull request:

- Review your own changes.
- Run the relevant tests, linting, and type checks.
- Update documentation when behavior changes.
- Complete the pull request template accurately.

Submitting a contribution does not guarantee that it will be accepted or merged.

## General Inquiries

For general questions or inquiries, contact us at `hello@hachiva.com`.
