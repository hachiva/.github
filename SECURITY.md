# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in a Hachiva repository or service, please report it privately by emailing:

**security@hachiva.com**

Please include:

- A description of the vulnerability
- Steps to reproduce the issue
- The affected repository, product, or service
- Any relevant screenshots, logs, or proof-of-concept details
- The potential impact, if known

Please do not disclose security vulnerabilities through public GitHub issues, discussions, or pull requests.

We will review valid reports and respond as soon as reasonably possible.

## Scope

This policy applies to repositories and services maintained by the Hachiva organization.

Third-party dependencies and services may be subject to their own security policies.
