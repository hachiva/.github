# Support

## Bug Reports

If you encounter a reproducible bug in a public Hachiva repository, please use the repository's bug report form.

Before submitting an issue:

- Search existing issues for similar reports.
- Include clear reproduction steps.
- Provide relevant environment and version details.
- Do not include credentials, secrets, personal data, or other sensitive information.

## Feature Requests

Use the repository's feature request form to suggest improvements or new capabilities.

Please describe the underlying problem, the expected outcome, and any alternatives you have considered.

## Security Vulnerabilities

Do not report security vulnerabilities through public issues, discussions, or pull requests.

Please follow our [Security Policy](SECURITY.md) or contact `security@hachiva.com`.

## General Inquiries

For general questions, partnerships, or other inquiries, contact `hello@hachiva.com`.

## Support Availability

Hachiva does not currently provide guaranteed response times or dedicated technical support for public repositories.
